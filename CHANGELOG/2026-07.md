# Changelog — 2026-07

### 2026-07-01 — test: add check-enc-pod (R10 witness for the enc externalization, C16a)

Adds the `check-enc-pod` disposable bed (+ `check-enc-pod-volume` `type: encrypted` deploy volume) to
`charly.yml`, reusing the light `check-pod` fedora-minimal image. It is the sole R10 witness for the
superproject's C16a cutover (gocryptfs mount mechanics → `candy/plugin-enc`): the bed's `charly config` step
drives the in-core enc shim → `verb:enc` `OpExecute` → a real `gocryptfs -init` + `systemd-run --scope --user`
mount on the host, after which the container binds the FUSE plain dir. Checks: `enc-status-mounted` (host-side
`charly config status` reports the volume initialized + mounted) and `enc-plain-writable` (an in-container
write to the mount point reads back). Passphrase via the `GOCRYPTFS_PASSWORD` env hook; the bed host needs
gocryptfs + fusermount3 + `user_allow_other` in `/etc/fuse.conf` + a user systemd session.

Verified: `check-enc-pod` PASS (steps=10) on a fresh `task build:charly` rebuild.
