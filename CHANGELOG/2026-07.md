### 2026-07-01 — test: assert welded commands resolve project-less on the .rpm install (check-fedora-vm)

Added a `welded-command-project-less` check step to the `check-fedora-vm` bed. The
existing `localpkg-rpm-autoresolve` step asserted only `charly version` (a core command
that always resolves), so it could not catch the packaging gap where the `.rpm` shipped
only the binary without the welded `command:<word>` plugins. The new step asserts the
baked plugins are present at `/usr/lib/charly/plugins` (`plugin-doctor`/`plugin-vm`/
`plugin-clean` + `plugin-doctor.providers`) AND that a project-less `charly doctor`
actually dispatches through the baked `command:doctor` plugin
(`WELDED-CMD-PROJECT-LESS-OK`) — it FAILS on a package that shipped only the binary.
Pairs with the `pkg/fedora` `.rpm` plugin-baking fix.
